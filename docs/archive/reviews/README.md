# Review Transcript Archive

Historical external-review transcripts may exist locally as ignored files, for
example `review.txt` or `website-reivew.md`. They are intentionally excluded by
`.git/info/exclude` and are not current project truth.

When a review conclusion needs to become authoritative, copy the relevant
decision into a tracked report or Day capsule and link the source context here.
