# Review Transcript 归档

历史外部 review transcript 可能以本地 ignored 文件存在，例如 `review.txt` 或
`website-reivew.md`。这些文件可以辅助分析，但不是项目权威事实。

当某个 review 结论需要成为项目事实时，必须把相关决策复制到 tracked report 或 Day
胶囊中，并在这里链接来源上下文。
