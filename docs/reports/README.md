## 维护规则

- 每个 Phase 完成后，应新增或更新对应的阶段报告。
- 每次跨 Phase 复盘，应输出一份 QA 报告和一份项目经理报告。
- 报告必须引用 Day 文档、Phase 文档、风险台账或缺口台账，不允许只写主观判断。
- 报告结论必须区分“开发可用”“集成可用”“生产可用”，不得用局部验证代替生产放行。
