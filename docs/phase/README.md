# Phase 完工报告索引

本目录只放已经完工并完成 gate / acceptance 的 Phase 报告。

规则：

- Phase 未出关前，不创建对应 `phase-x.md` 完工报告；
- 阶段内的过程证据、临时报告和详细审查材料继续保存在 `docs/archive/`；
- 本目录中的报告负责给长期回顾者快速判断阶段目标、结论、证据和遗留风险；
- 如果某个 Phase 后续被复审或结论变化，必须同步更新对应 `phase-x.md`。
